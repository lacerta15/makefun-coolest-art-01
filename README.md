**Ember Eye** — five million iterations of a single chaotic equation (a Clifford strange attractor) fold into a glowing iris: teal ribbons threaded with molten magenta and gold veins converging on a dark pupil at the center of the storm. Fully deterministic, no network access, no external assets.

## Run it

```sh
python main.py
```

Writes `output/entry.png` (1024×1024 PNG). Running it twice produces byte-identical output.
